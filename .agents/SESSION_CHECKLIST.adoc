== Session Procedure

=== Debut de Session

* [ ] Mission injectee par opencode (configuration/.agents/PROMPT_REPRISE.adoc)
* [ ] Lire INDEX.adoc (regles absolues + etat EPICs)
* [ ] Lire AGENT.adoc (regles absolues)
* [ ] Lire SESSION_PROCEDURE.adoc (procedure de travail)
* [ ] Charger les fichiers ESSENTIALS si l'EPIC est concernee

=== Fin de Session (6 etapes obligatoires)

==== Etape 1 : Archive session

* [ ] Creer l'archive LAZY : `.agents/sessions/{N}-{type}-{sujet}.adoc`
* [ ] Template obligatoire : contexte, actions, commandes, resultats, lecons
* [ ] Ne pas laisser le fichier vide

==== Etape 2 : Mission N+1

* [ ] Mise a jour `configuration/.agents/PROMPT_REPRISE.adoc` — Mission N+1 (max 70 lignes)
* [ ] Ne pas depasser 70 lignes
* [ ] Ecrire Concis, pas de vague

==== Etape 3 : Dashboard N+1

* [ ] Mise a jour INDEX.adoc
* [ ] Ajouter la session terminee (date, numeros, EPICs concernees)
* [ ] Mettre a jour etat EPICs (progression, blocages, termines)
* [ ] Mettre a jour portefeuille (ajouter/supprimer projets)

==== Etape 4 : Historique

* [ ] Mise a jour `.agents/SESSIONS_HISTORY.adoc`
* [ ] Ajouter entrée : date, session N, EPICs, livrables
* [ ] Ne pas oublier les sessions sans EPIC (debug, refactoring, etc.)

==== Etape 5 : Tests

* [ ] Mise a jour `.agents/TEST_COVERAGE_ANALYSIS.adoc` (si tests modifies)
* [ ] Ajouter: nouveaux tests, modifications, suppression
* [ ] Mettre a jour couverture, stats, benchmarks

==== Etape 6 : Archivage mensuel

* [ ] Si session multiple de 10 (N % 10 == 0) :
* [ ] Creer le dossier `.agents/backup/Y{annee}-sessions-{plage}/`
* [ ] Y copier INDEX, SESSIONS_HISTORY, COMPLETED_TASKS_ARCHIVE
* [ ] Tronquer fichiers actifs aux 10 dernieres sessions
* [ ] Mettre a jour INDEX.adoc avec localisation de la nouvelle vague

* [ ] Si fichiers EAGER cumules > 500 lignes (wc -l) :
* [ ] Meme procedure que ci-dessus (backup + troncature)

== Gestion des Secrets

* [ ] Aucun token/password/API key dans le code ou les logs
* [ ] `grep -r "TOKEN\|SECRET\|PASSWORD\|API_KEY\|gho_\|ghp_"` en fin de session
* [ ] Retirer les faux-positifs (ex: `tokenRef: $TOKEN` n'est pas un leak)

== Verification Post-Session

* [ ] Build compile (`./gradlew build -x test`)
* [ ] Tests unitaires (si permission donnee)
* [ ] Tests Cucumber (si permission donnee)
* [ ] Aucun warning ou error critique

== Checklist Rapide (30 secondes)

1. [Archive session cree?]
2. [PROMPT_REPRISE mis a jour?]
3. [INDEX.adoc mis a jour?]
4. [SESSIONS_HISTORY mis a jour?]
5. [Test coverage mis a jour?]
6. [Backup lance si besoin?]
7. [Aucun secret trace?]
8. [Build compile?]
