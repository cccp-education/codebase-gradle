== Anti-patterns tests

| # | Anti-pattern | Symptome | Correction |
|---|--------------|----------|------------|
| 1 | **Timeouts flaquants** | Tests Cucumber échouent unpredictably | Augmenter les timeouts (5min→8min) |
| 2 | **PostgreSQL slow startup** | 15s avg, CI flakiness | Reuse container, longer timeouts |
| 3 | **Test doubles incomplets** | Fake non representatif de la production | Rapprocher des vrais providers |
| 4 | **Tests trop longs** | >30min Cucumber | Splitter en suites plus petites |

== Plans d'amélioration

=== Court terme (2-4 semaines)

1. Fixer les timeouts Cucumber (5min→8min)
2. Améliorer les fake providers (FakeVisionProvider, FakeOllamaOcrProvider)
3. Automatiser la detection de secrets dans les logs

=== Moyen terme (1-2 mois)

1. Réduire le temps de setup PostgreSQL (Reuse container)
2. Ajouter des tests E2E complet (end-to-end)
3. Améliorer la couverture Cucumber (plus de scénarios réels)

=== Long terme (3-6 mois)

1. Migration vers Testcontainers 2.0 (meilleure isolation)
2. Cypress/Playwright pour tests UI Swing (Javelit)
3. Benchmark continuous (regression detection)
