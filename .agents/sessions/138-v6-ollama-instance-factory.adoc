== Leçons apprises

* Pour modéliser le pattern Docker Ollama Pro, il suffit d'un tag métier de volume dans `LlmInstance` ; l'auth SSH reste côté conteneur.
* Un contrat N0 publié peut évoluer de façon backward-compatible avec un champ nullable ; pas besoin de publier immédiatement, `mavenLocal` suffit pour le développement intra-workspace.
* Les scénarios BDD sur Ollama cloud doivent rester sans réseau en test : le comportement de rotation est dans l'adaptateur de pool, pas dans l'appel HTTP.
