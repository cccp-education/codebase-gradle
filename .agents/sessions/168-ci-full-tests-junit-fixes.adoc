== Leçons

* `String.format()` sans Locale explicite = bug latent en CI (Locale JVM par défaut)
* Les attendus de tests de comptage doivent suivre l'évolution du plugin (register ajoutés)
* Lancer `./gradlew` en subprocess depuis un test Gradle = anti-pattern (conflit daemon/catalog)
* `@Tag("integration")` + `excludeTags` JUnit5 = mécanisme propre pour tests env-dependents
* `llm-config.yml` gitignoré ne peut pas être chargé en CI — tagger les tests qui le référencent
