restent (vocabulaire commun de production de contenu) ; seules les
marques et les listes de détection métier sortent.

== Leçons

1. *Transfuser avant de neutraliser* : le pattern US-0 (extraire la
   logique métier → document vivant training) évite la perte de savoir
   métier pendant la purge OSS. À répliquer par borough.
2. La nuance D5/D11 (« sigles publics conservables en détection ») était
   un compromis fragile : le detector identifiait le métier par ses
   sigles — ils sont ipso facto métier. Abrogés sans état d'âme.
3. Les traces d'audit (`ex-FPA`, `FpaPageResolver`) sont légitimes dans
   les cadrages si explicitement marquées comme historiques (note en
   tête du cadrage) — le grep gate vise src/ + docs courantes, pas
   l'historique.
