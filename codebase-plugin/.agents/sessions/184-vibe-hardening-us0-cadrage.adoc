== Audit code cible (3 findings P1)

=== S1 — Blacklists shell/gradle bypassables

`ExecShellTool.kt:10-21` — 10 regex `BASH_BLACKLIST` :
* `rm -rf` → `rm -Rf` (case-insensitive ne couvre pas `-Rf`)
* `chmod 777` → `chmod 0777` (regex `chmod\\s+777` ne matche pas `0777`)
* `curl 127.0.0.1` = faux positif (localhost IP bloqué par regex curl)

`ExecGradleTool.kt:10-15` — 4 regex `GRADLE_BLACKLIST` :
* `clean  build` (double espace) passe `clean\\s+build` (exige 1 séparateur exact)

=== C2 — retryCount double-compté

`VibecodingGraph.kt:580-607` — `executePlanTasks` incrémente `retryCount` (L587, L604).
`VibecodingGraph.kt:277-313` — bloc error recovery incrémente encore (L291, L298, L302).
= 2 incréments/essai → maxRetries=3 épuisé en 2 essais.

`VibecodingState.withRecoverableError` (L46-47) incrémente déjà — doublon.

=== C5 — LLM sans timeout

3 sites `runBlocking { llmProvider.call(...) }` sans `withTimeout` :
* `VibecodingGraph.kt:413` (callLLMNode)
* `VibecodingGraph.kt:288` (replan error recovery)
* `StepVerifier.kt:44` (replan verifyAndAdapt)

Ollama gelé = build bloqué indéfiniment (timeout session vérifié entre itérations seulement).
