== Leçons

* Séparer le port `InvalidChunkRepository` du repository principal `AgenticChunkRepository` respecte DDD : deux bounded contexts différents (chunks valides vs chunks invalides).
* Utiliser une classe JSON intermédiaire (`ChunkValidationErrorJson`) pour la sérialisation PostgreSQL évite de marquer la classe domaine `ChunkValidationError` avec `@Serializable`, qui est du ressort de l'infrastructure.
* `InMemoryInvalidChunkRepository` suffit pour le fallback local et les tests sans Testcontainers.
* La quarantaine ne doit pas bloquer l'ingestion des chunks valides : elle est un sous-compteur et une liste de diagnostic.
