== Leçons apprises

* **Tag `@integration` sur feature ne suffit pas** : chaque runner dédié doit aussi exclure
  `@integration` dans son filtre `FILTER_TAGS_PROPERTY_NAME`. Sinon le scénario s'exécute
  via le runner dédié même s'il est exclu du runner générique.
* **Workflow CI non testé localement avant commit** : le workflow `ingest-governance.yml`
  (session 160) appelait une task inexistante — aurait dû être testé via
  `./gradlew :codebase-plugin:ingestGovernance` avant commit.
* `gh run view --log --job=<id>` est l'outil de debug CI le plus efficace — donne les
  stack traces complètes avec contexte.
