== Leçons

* `dependsOn` avec String n'est pas visible via `task.dependsOn` cast
  `TaskReference` dans `ProjectBuilder` — utiliser `taskDependencies.
  getDependencies(task).map { it.name }` (API Gradle stable pour résoudre
  les dépendances lazily-resolved).
* `ProjectBuilder` + `tasks.register("exposeExperts", ...)` dans une tâche
  qui assume que `CodebasePlugin` a déjà enregistré `exposeExperts` →
  DuplicateTaskException. Solution : `findByName` + fallback `register`
  (idempotent, testable isolément).
* Test `contains("0.10")` fragile — Kotlin `Double.toString()` supprime le
  zéro final (`0.1`). Utiliser `contains("corpus ratio: 0.1")` (exact
  formatted string) au lieu de `contains("0.10")`.
* Pattern `@Internal var pipeline: FineTuningPipeline?` + lazy default
  `buildDefaultPipeline()` : la tâche reste testable avec `FakeFineTuner`
  ET fonctionne en production avec `OllamaFineTunerAdapter` sans
  modification.
