== Leçons

. *Baby-step TDD sur validation* : écrire les tests positifs ET négatifs
  avant de modifier la logique. Les tests négatifs (`bare value without
  preceding flag`, `value after -P property`) sont restés PASSED à
  travers RED/GREEN — ils garantissent que la nouvelle porte ne crée
  pas de trou de sécurité.
. *Cache Gradle* : `--rerun-tasks` obligatoire pour voir les tests
  après modification de production ET de test dans la même passe. Sans
  ça, `UP-TO-DATE` masque les résultats.
. *Allowlist paire flag+value* : la sécurité reste deny-by-default. Un
  token valeur n'est accepté que s'il suit immédiatement un `bareLongFlag`
  reconnu, ne commence pas par `-`, et ne contient pas `;&|`. Defense in
  depth préservée.
