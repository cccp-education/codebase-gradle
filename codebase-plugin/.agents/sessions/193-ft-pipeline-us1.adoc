== Leçons

* Le pattern `CapsuleConfigMerger` (494 lignes) est surdimensionné pour un
  domaine à 5 champs — merger réduit à 3 helpers génériques + 2 loaders.
* Int/Double n'ont pas de concept "blank" (contrairement aux String) — pas de
  fallback isNotBlank pour les scalaires, YAML/props gagnent toujours sur ENV.
* `epochs=0` lèverait l'invariant à la construction — le test "blank YAML
  fallback" n'a pas de sens pour les scalaires (retiré au profit de NoYaml
  defaults).
