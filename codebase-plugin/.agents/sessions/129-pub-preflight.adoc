== Leçons

* La publication Central est une porte de sortie, pas une étape productive quand on est le seul consommateur local. Pivoter vers la gouvernance locale/auto-alimentée respecte DOGFOOD FIRST.
* `constraints { implementation(...) }` ne force pas la résolution ; `resolutionStrategy.eachDependency` est nécessaire quand plusieurs transitives demandent des versions incompatibles.
* Le `.agents/` de codebase-gradle n'avait pas été maintenu depuis la session 084 ; cette session rétablit le fil de l'historique.
* Un `GovernanceContextLoader` simple et testé est plus utile immédiatement qu'un artefact publié sur Central.
