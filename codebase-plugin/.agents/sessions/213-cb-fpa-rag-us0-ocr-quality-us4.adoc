== Leçons

1. Cucumber `{boolean}` n'existe pas — `{word}` capture les guillemets
   littéraux, parser soi-même.
2. `"%.2f".format()` est locale-dépendante — toujours `Locale.US` pour
   les markers contextuels (règle réaffirmée S-168).
3. Les overrides de stubs doivent couvrir TOUTES les variantes de la
   surface (searchBlocking ET searchWithDoubtBlocking) — un channel
   basculé sur une nouvelle variante casse le stub incomplet.
4. Le RED peut venir de l'exposition (data class) aussi bien que des
   méthodes — `RagVectorStoreDoubtTest` mixe réflexion (méthodes) et
   compilation (champs), complémentaires.
