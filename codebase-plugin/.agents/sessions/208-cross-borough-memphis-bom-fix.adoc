  artifactId `slider`. Depuis l'aplatissement structure slider S-067

  `slider-plugin`.

  `slider:0.0.18` → bug. Le commit `d1e4e84` "publish slider 0.0.18" a
  publié le nouvel artifactId mais le BOM n'a pas suivi.

=== Cascade bloquante

Le fix catalogue seul est insuffisant. La chaîne de résolution Gradle :

----
capsule → BOM 0.0.27 (fix, slider-plugin:0.0.18 ✅)
       → codebase 0.0.9 (POM Central)

l'ancien `slider:0.0.18`. Tant que codebase 0.0.9 importe BOM 0.0.24, la
résolution Gradle voit deux artefacts concurrents (`slider` + `slider-plugin`)
