== Architecture livrée (N1)

=== `codebase.koog.pipeline.PipelineDefinition<S>` (port)

```kotlin
interface PipelineDefinition<S> {
    val name: String
    fun propose(state: S): S
    fun validate(state: S): S
    fun generate(state: S): S
    fun isValid(state: S): Boolean
    fun isFailed(state: S): Boolean
    fun onProposeFailure(state: S, cause: Throwable): S
    fun onGenerateFailure(state: S, cause: Throwable): S
}
```

Toute la connaissance domaine (LLM, prompt, validation, libellés) vit derrière
ce port. Le squelette ignore capsule/slider.

=== `codebase.koog.pipeline.PipelineGraph<S : Any>` + `pipelineGraph`

* `execute(initial)` — orchestration séquentielle fail-fast : `propose`
  (try/catch → `onProposeFailure`), court-circuit si `isFailed`, `validate`,
  court-circuit si `!isValid`, `generate` (try/catch → `onGenerateFailure`).
* `graph: AIAgentGraphStrategy<S,S>` — topologie koog
  `strategy<S,S>` + 3 nœuds + 5 edges.
* `asMermaidDiagram()`.
* `pipelineGraph(definition)` — **`inline` + `reified S: Any`** : koog's
  `strategy`/`node` résolvent leur `TypeToken` via des paramètres `reified`
  (vérifié dans les sources koog : `inline fun <reified Input, reified Output>
  strategy(...)` / `node(...)`). Une classe générique simple ne pourrait pas
  appeler ces builders ; la factory inline laisse `S` être inféré au call site
  d'adoption (ex. `PipelineDefinition<CapsuleState> → S = CapsuleState`).

== Leçon

* Un scenario Cucumber dont le step `{string}` est appelé **sans guillemets**
  compile, s'exécute, et échoue en `UndefinedStepException` **à l'exécution**
  (invisible en compilation locale). Les tests sont en CI — d'où l'importance
  du run CI comme unique preuve.
* koog `strategy`/`node` sont `inline reified` : un squelette générique doit
  passer par une **factory inline reified**, pas une méthode générique.
