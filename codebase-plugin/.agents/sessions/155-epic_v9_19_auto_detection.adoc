== Leçons

* L'approche DDD/TDD baby-step a permis d'isoler le diff incrémental dans des value objects purs testables sans Gradle, puis de les câbler progressivement. Le `GovernanceFileChangeDetector` ne dépend d'aucune infrastructure — il aurait pu être testé en premier.
* La persistance JSON custom (regex) a été un compromis pragmatique pour éviter une dépendance JSON parser. La méthode `load()` défensive (null si fichier absent/vide/JSON invalide) garantit la robustesse face à un état corrompu.
* Le mode incrémental est rétrocompatible par défaut (`incremental=false`), ce qui préserve tous les tests existants sans modification.
* La contrainte Ollama a été sauvegardée à deux niveaux (global `AGENTS.adoc` + borough `AGENT.adoc`) pour être chargée à chaque ouverture de session.
