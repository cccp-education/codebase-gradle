== Leçons

* Cucumber glue est global au classpath : tout step def avec le même wording
  provoque `DuplicateStepDefinitionException` même entre runners tagués différemment.
  Préfixer les steps par EPIC pour isoler.
* Les caractères regex méta (`.` `/`) dans les wording de step def Cucumber peuvent
  causer des "undefined" subtils — préférer des wording simples sans chemin de fichier.
* `FakeXxx` dans `src/test` n'est pas accessible depuis `src/main` — porter vers
  `InMemoryXxx` dans main quand une tâche Gradle de production en a besoin.
