== Actions

=== VectorStore.ensureSchema()
Ajout d'une méthode non-destructive (`CREATE TABLE IF NOT EXISTS`) pour l'ingestion
sans écraser les données existantes. `initSchema()` reste destructif pour les tests.

=== OcrIngestTask
Nouvelle tâche Gradle `ocrIngest` (groupe `collect`) :
- Lit les fichiers `.adoc` depuis `build/ocr/`
- Chunking via `ChunkTokenizer.splitIntoSentenceLevelChunks()`
- Insertion documents+chunks dans pgvector via `VectorStore.insertDocument()`
- Embedding ONNX AllMiniLmL6V2 via `EmbeddingPipeline.embedAll()`
- Options CLI : `--ocrOutputDir`, `--jdbcUrl`, `--jdbcUser`, `--jdbcPassword`
- Résilient : répertoire absent → warning, pas de crash

=== CodebasePlugin
Enregistrement `ocrIngest` avec convention `ocrOutputDir = build/ocr/`.

=== Tests JUnit5 — OcrIngestTaskTest (14/14 PASS)
Testcontainers `pgvector/pgvector:pg17` :
- Registration + groupe
- Répertoire vide → 0 document
- Single file → chunk + embed
- Multi files → 3 documents
- Filtre .adoc uniquement
- Idempotence
- ensureSchema préserve données existantes
- Queryable via RAG (similarité vectorielle)
- Contenu anonymisé queryable
- Répertoire inexistant → pas de crash
- JDBC URL custom
- Document large → multiple chunks
- E2E : image→OCR→anonymize→ingest→query

=== Cucumber — OcrIngestSteps (5/5 @epic_ocr_4_ingest PASS)
