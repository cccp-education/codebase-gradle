== Livrable — adoption du catalog workspace (pattern bakery MEM-CAT-3)

* `settings.gradle.kts` — pin unique `ws` :
[source,kotlin]
----

    versionCatalogs {
        create("ws") { from("education.cccp:workspace-catalog:0.0.62") }
    }
}
----

* `build.gradle.kts` — version propre **dérivée** :
[source,kotlin]
----
version = ws.versions.codebase.plugin.get()
----

* BOM platform **dynamique** (plus de littéral périmé) :
[source,kotlin]
----
implementation(platform("education.cccp:workspace-bom:${ws.versions.workspace.bom.get()}"))
----

* Self-application **alignée** sur le toml (source unique) :
[source,kotlin]
----

----

* Entrée toml `workspace-bom = "0.0.50"` **supprimée** (source de vérité = ws).
* Preuve : `./gradlew properties` → `version: 0.0.17` ; POM
  `codebase-plugin-0.0.17.pom` → `version 0.0.17` + import `workspace-bom 0.0.62`.

== Livrable — garde anti-drift publication

`src/test/kotlin/codebase/publishing/CodebasePluginPublicationTest.kt` (4 tests,
pattern `BakeryPluginPublicationTest` S-244) :

. la version dérive du catalog publié (`version = ws.versions.codebase.plugin.get()`) ;
. la version self du toml local **égale** la version du catalog ws ;
. le pin `workspace-bom` platform est **dynamique** (aucun littéral `0.0.\d+`) ;
. group + plugin id stables pour la publication.

Injection des versions publiées par Gradle (`build.gradle.kts`) — **jamais** de
lecture du working tree voisin (racy, absent d'un checkout CI isolé — bakery
S-243 / graphify D5-RACE S-029) :

[source,kotlin]
----
tasks.named<Test>("test") {
    systemProperty("codebase.publishedCatalog.codebaseVersion", ws.versions.codebase.plugin.get())
    systemProperty("codebase.publishedCatalog.bomVersion", ws.versions.workspace.bom.get())
}
----

Une propriété absente est une **erreur explicite**, jamais un vert silencieux.
