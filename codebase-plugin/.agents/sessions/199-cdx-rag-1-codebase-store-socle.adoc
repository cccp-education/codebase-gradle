== Leçons

* *Verbatim migration* : la copie est délibérée (pas un refactor). Les
  characterization tests mirroir verrouillent le contrat comportemental
  avant que RAG-2 ne rewire les call sites. Le risque de divergence
  est nul tant que les deux classes coexistent.
* *Types autonomes* : `DocumentChunk` et `RetrieveResult` migrent dans
  `codebase.store` (pas d'import `codex.tasks.*`). Le store devient
  autonome — prérequis pour RAG-4 (retrait `libs.codex.plugin`).
* *Bump préventif* : aligner les versions avant de coder évite le drift
  pendant RAG-1/RAG-3. Le pattern C-BOM-FIX (versions explicites dans
  `libs.versions.toml`) outrepasse la BOM — bump explicite obligatoire.
