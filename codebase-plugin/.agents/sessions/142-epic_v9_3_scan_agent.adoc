== Leçons

- `@TempDir` JUnit n'est pas compatible avec Cucumber (instantiation via constructeur).
  Pattern maison : `Files.createTempDirectory` dans le World + reset par `deleteRecursively`.
- `--rerun-tasks` nécessaire quand Gradle considère les resources de feature inchangées
  mais que le test doit rejouer (cache inputs/outputs).
- Baby-step DDD/TDD/BDD confirmé : contrat DDD (test rouge) → value object → domain service
  (vert) → refactor integration → Cucumber BDD. Un fichier à la fois, compilation entre chaque.
