== Actions

1. Ajout dépendance `education.cccp:i18n-contracts:0.0.1` (présent dans
   mavenLocal) au catalogue root `gradle/libs.versions.toml` + build.gradle.kts
   du codebase-plugin.
2. Création du contrat N0 `TranslationService` dans
   `src/main/kotlin/contracts/i18n/TranslationService.kt` :
   - interface `TranslationService.translate(TranslationRequest): TranslationResult`
   - data class `TranslationRequest` (sourceText, sourceLanguage, targetLanguage)
     avec invariants (non-blank, src != tgt)
   - sealed class `TranslationResult` (Success / Failure)
3. Implémentation N1 production `LlmTranslator` dans
   `src/main/kotlin/codebase/i18n/LlmTranslator.kt` :
   - wrap `codebase.koog.llm.LlmProvider` (Gemini/Ollama en prod, FakeLlm en test)
   - prompt minimal "Translate from <src> to <tgt>:<text>"
   - sanitize quotes/guillemets, gestion exception → Failure
4. Fake `FakeLlmTranslator` dans `src/test/kotlin/codebase/i18n/` :
   - déterministe sans réseau, file FIFO de résultats, capture requêtes
5. Tests JUnit5 :
   - `LlmTranslatorTest` — 6 tests (success, blank→Failure, exception→Failure,
     prompt content, same-lang rejected, blank source rejected)
   - `FakeLlmTranslatorTest` — 2 tests (default stub, FIFO enqueued)
6. Feature Cucumber `epic_translation.feature` — 6 scénarios @epic_translation :
   - Fake stub, FIFO enqueued success, enqueued failure, LlmTranslator sanitize
     quotes, LlmTranslator blank→Failure, same-lang IllegalArgumentException
   - `TranslationWorld`, `TranslationSteps`, `EpicTranslationCucumberRunner`
   - Tâche Gradle `cucumberTestEpicTranslation` enregistrée dans build.gradle.kts
