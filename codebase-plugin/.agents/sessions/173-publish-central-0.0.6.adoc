== Leçons

. **Central Portal validation** : `<name>` et `<description>` sont obligatoires
  dans le POM. Le `PublishingConventionsPlugin` (conventions-gradle 0.0.2) ne les
  set pas — il faudrait l'enrichir pour éviter ce fix manuel dans chaque borough.
. **nmcp AUTOMATIC** : `publishingType = "AUTOMATIC"` publie sans intervention
  manuelle sur le portal UI. Le statut passe de VALIDATING → PUBLISHING.
. **Propagation delay** : Maven Central met 10-30 min pour propager. Ne pas
  paniquer si HTTP 404 immédiatement après BUILD SUCCESSFUL.
