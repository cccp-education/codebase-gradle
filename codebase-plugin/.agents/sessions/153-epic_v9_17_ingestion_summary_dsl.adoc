== Contexte

== Actions

. Création de l'extension Gradle `CodebaseGovernanceExtension` avec `toConfig()` DDD.
. Câblage dans `CodebasePlugin` : enregistrement de l'extension `codebaseGovernance` + lecture prioritaire de la propriété `codebase.governance.strictValidation`.
. Refactor de `IngestGovernanceTask` :
  * ajout de `governanceConfig: Property<GovernanceSummaryConfig>`
  * point d'entrée DDD `executeIngest(root, config, output)`

== Leçons

* Garder un modèle DDD pur (`GovernanceSummaryConfig`) séparé de l'extension Gradle permet de tester la logique sans Project/Task.
* `project.providers.gradleProperty()` ne lit pas les `extraProperties` de `ProjectBuilder` ; utiliser un vrai `gradle.properties` dans le répertoire projet pour les tests CLI override.
* La rétrocompatibilité se paie avec une convention par défaut `false` et une double source de vérité temporaire (`strictValidation` task property + `governanceConfig.strictValidation`) ; la prochaine étape V-9.18 doit déprécier la propriété task interne au profit de l'extension.
