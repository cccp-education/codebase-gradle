== Leçons

* **Anti-pattern detection** : un artefact supprimé du workspace-bom peut encore être référencé par des boroughs via MavenLocal. Le build compile mais la publication Central casse. La règle DAG nmcp (toutes les deps `education.cccp:*` doivent être sur Central) est un garde-fou précieux.
* **Git history comme sauvegarde** : `git checkout <sha> -- <path>/` permet de restaurer un module complet supprimé, avec build/scripts/tests. Plus sûr que de réécrire.
* **Convention nmcp uniforme** : tous les modules N0 de workspace-bom utilisent exactement le même pattern `settings.gradle.kts` (nmcp 1.5.0 + centralPortal AUTOMATIC + globalProps). Reproduire ce pattern est trivial.
* **Baby-step respecté** : 1 fichier à la fois, compilation après chaque édition, tests ciblés après suppression du doublon. Pas de parallélisation.
