## Flaky débusqué et tué : pollution du conteneur persistant

Le conteneur Testcontainers pg17 est un **singleton persistant partagé entre
sessions et classes de test**. Deux surfaces de flakiness découvertes et
corrigées :

* le test ne passait que **isolé** — pas en suite globale : les lignes laissées
  par les run précédents (contenu <token>semblable) faisaient sortir les chunks
  attendus du **topK global** (tie-breaking arbitraire sur embeddings
  identiques) ;
* `RagVectorStorePageProvenanceTest` (US-1, HEAD) ne purgeait que son **propre
  UUID** → résiduel inter-sessions.

Fix : les deux tests balayent désormais **toute la famille fermée**
(`page-provenance-test-%` OU `page-exposition-test-%`) en setup. + jeton unique
`marker = traceable-<uuid>` dans le contenu de l'US-3, requête
`"$marker competences"`, assertions réancrées sur `sourceDocument` (la ligne
meta porte le source, pas le marker). Résiduel préexistant purgé une fois
(`DELETE 11`).
