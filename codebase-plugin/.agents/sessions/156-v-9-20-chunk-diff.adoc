== Leçons

* Le parser regex de `JsonGovernanceStateStore` (V-9.19) ne gère que 2 champs
  par objet. Pour `ChunkSnapshotEntry` (4 champs), extension du pattern regex
  à 4 groupes capturants — même style maison, pas de Jackson ajouté.
* `GovernanceIngestor.IngestResult` ne portait pas la `ChunkSnapshot` —
  enrichi pour exposer l'état des chunks après ingestion (via
  `InMemoryAgenticChunkRepository.listChunks`).
* Le câblage CLI `CodebasePlugin` chaînait `orElse` (mutuellement exclusif) —
  refactor en `project.provider` composant les 3 propriétés CLI
  indépendamment (strictValidation + incremental + chunkIncremental).
* `mergeChunkSnapshots` : en mode fichier incrémental, on retire les chunks
  des fichiers modifiés/supprimés de la snapshot précédente, puis on ajoute
  les nouveaux chunks. Les fichiers inchangés conservent leurs chunks
  précédents (pas de réingestion).
