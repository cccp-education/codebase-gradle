== Leçons

- Jackson `Instant` sérialisation nécessite `jackson-datatype-jsr310` (ajouté aux 2 catalogues TOML)
- `requireSessionId()` assouplie : accepte IDs non-UUID (le lifecycle manager est agnostique)
- `updateResponse()` passe le statut CREATED→RUNNING automatiquement
- Resume crée un nouvel enfant avec `parentSessionId`, conserve le prompt original
