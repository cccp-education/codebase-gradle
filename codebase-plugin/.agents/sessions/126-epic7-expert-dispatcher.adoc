== Leçons

- R2DBC `bind()` n'accepte pas les valeurs null → utiliser `bindNull()` pour les champs nullable
- `Mono.from(conn.close()).awaitSingle()` échoue (Publisher<Void>) → utiliser `.subscribe()`
- `awaitSingleOrNull()` n'existe pas → utiliser `.collectList().awaitSingle().firstOrNull()`
- Cucumber est strict sur singulier/pluriel dans les steps
