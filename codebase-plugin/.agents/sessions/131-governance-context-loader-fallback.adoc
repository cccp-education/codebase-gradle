== Contexte

Session 130 avait livré koog 1.0.0 (replacement `forwardTo`) et créé `GovernanceContextLoader`. La mission 131 était de câbler ce loader en fallback auto dans `SessionProtocolTask` et `SessionProtocolServer` quand aucun `--contextFile` / `context` n'est fourni.

Au cours des tests, l'utilisateur a signalé que les tests utilisaient des ports Ollama interdits (11434) et des modèles non autorisés (`qwen3-vl:235b-cloud`, `deepseek-v4-pro:cloud`, `gpt-oss:20b-cloud`). Directive stricte : ports 11437-11465 uniquement, modèle `gpt-oss:120b-cloud`.

== Actions

1. **Câblage `SessionProtocolTask`** : fallback auto via `GovernanceContextLoader().load(workspaceRoot)` si `contextFile` absent. Ajout d'un champ `lastAgentContext` exposé pour les tests.
2. **Câblage `SessionProtocolServer`** : fallback auto si `sessionPrompt.context` absent. Ajout d'un champ `lastAgentContext`.
3. **Tests unitaires** : 2 tests dans `SessionProtocolTaskTest`, 1 test dans `SessionProtocolServerTest`.
4. **Compliance ports/modèles** : correction de toutes les occurrences de `11434`, `qwen3-vl:235b-cloud`, `deepseek-v4-pro:cloud`, `gpt-oss:20b-cloud` dans `src/main` et `src/test`. Distribution des ports dans les tests multi-instances (11437-11465).
