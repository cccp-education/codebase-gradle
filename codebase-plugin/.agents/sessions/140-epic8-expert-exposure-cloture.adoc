== Leçons

- Les types privés `@Serializable` dans deux fichiers du même package
  Kotlin ne doivent pas porter le même nom (`ManifestJson`/`ExpertJson`
  dans `ExpertExposureTask.kt` + `ExpertManifestReader.kt`). Renommage en
  `Reader*Json` évite la collision sans polluer l'API publique.
- La step Cucumber `When it resolves the "kotlin" expert endpoint` doit
  matcher exactement l'annotation `@When("it resolves the {string}
  expert endpoint")` — le pronom "it" ne peut pas être implicite.
- Reframe du backlog : un item dépendant d'un autre borough
  (training-gradle TRN-8) ne doit pas bloquer la clôture côté codebase.
  Le baby step réalisable a été de fournir la porte de consommation
  (reader), pas d'attendre les modèles.
