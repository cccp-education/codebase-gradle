  facilement de l'INDEX racine `codebase-gradle/.agents/INDEX.adoc` quand
  les sessions s'enchaînent (S-186/187 non propagées). Double source de

  plugin en retard (S-185).
* Stale cosmétique dans les catalogues (alias `agent-contracts = "0.0.2"`
  dans BOM `libs.versions.toml` non référencé) est inoffensif mais
  trompeur pour un audit futur. À nettoyer côté MEMPHIS si déclencheur.
* Capsule-gradle utilise BOM 0.0.16 (périmé 3 versions) — sujet à
  remonter côté Détroit, pas Queens.
* C4 (flags GradleTaskArgsMapper) est un bug induit par US-2 (S-186) —
  l'allowlist deny-by-default a durci mais cassé les flags avec valeur.
  Pattern : durcissement → régression fonctionnelle → EPIC correctif.
