== Leçons

. Port interne `OllamaRegistryClient` (fun interface) est préférable à
  un stub `java.net.http.HttpClient` direct — la hiérarchie abstract
  `HttpClient` a trop de membres abstraits (`Optional<HttpResponse>`
  return type, `HttpHeaders.of(map, BiPredicate)`), rendant le stub
  verbeux et cassé en Kotlin. Le port interne isole le domaine de
  l'API HTTP et reste unit-testable via lambda.
. Pattern `FakeLlmTranslator` (FIFO queue + defaultResult + capture)
  directement réutilisé pour `FakeFineTuner` — zéro friction, le
  domaine DDD bénéficie du même socle de test que les autres ports.
. Fallback degraded "economy of ink" (pattern `AudioPostProcessor`/
  `ChatModelTranscriptEnhancer`) : l'adapter ne lève jamais pour un
  échec opérationnel — `Failure` avec dataset original préservé, le
  caller garde un état valide. Testé explicitement (4 scénarios
  Failure + 1 IOException).
. `RegistryResponse` sealed (Ok/Fail) + factory `ok`/`fail` évite les
  `Result<RegistryResponse, RegistryResponse>` ambigus et garde la
  signature lisible. Pattern identique à `FineTuningResult`.
