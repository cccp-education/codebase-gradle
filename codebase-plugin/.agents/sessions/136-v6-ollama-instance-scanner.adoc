= Session 136 — EPIC V-6 : OllamaInstanceScanner actif

== Contexte

Session 135 avait clôturé EPIC PUB. La mission 136 reprend EPIC V-6
(Ollama cloud dockerisé) pour remplacer le mode déclaratif `OLLAMA_POOL_PORTS`
par un scan actif des ports Ollama.

== Objectifs

. Implémenter [OllamaInstanceScanner] : scan actif `11437→11465` via `GET /api/tags`.
. Tests JUnit5 baby-step : fake scanner, fallback env var prioritaire, test d'intégration conditionnel.
. Câbler [LlmProviderResolver] pour utiliser le scanner quand `OLLAMA_POOL_PORTS` est absent.
. Maintenir la compilation et les tests existants.

== Actions Réalisées

|===
| Fichier | Action

| `port/InstanceScanner.kt` | Création port secondaire (probe HTTP)
| `port/EnvironmentReader.kt` | Création port secondaire (lecture env var)
| `HttpInstanceScanner.kt` | Implémentation HTTP réelle avec `java.net.http.HttpClient`
| `OllamaInstanceScanner.kt` | Domaine : scan plage, fallback env var, cycle 5 modèles

|===
