== Leçons

- Ne jamais supposer qu'Ollama n'est pas accessible en local sur les ports de la plage autorisée — les tests d'intégration conditionnels (`assumeTrue`) restent pertinents.
- Le `runBlocking` dans `callWithRotation` est nécessaire car `callOnInstance` est `suspend` mais le bloc de l'adapter est une lambda non-suspend.
- Découper le retry du provider (métier) du pool (domaine) respecte le DDD : l'adapter est un policy de résilience, pas une logique LLM.
