=== Bug #2 — collision de nom de tâche `generatePlan` (bloque SVO D5)

Les **deux** plugins enregistrent une tâche `generatePlan` (héritage EPIC K
K-1, commits `856b685` codebase + `b766f01` planner) → appliquer
`education.cccp.codebase` **et** `education.cccp.planner` au même projet
échoue (`Cannot add task 'generatePlan' as a task with that name already
exists`). Or c'est exactement le contrat SVO D5. Le contrat n'avait jamais
été exercé (aucun consommateur n'appliquait les deux plugins).

- **RED** : `CodebasePluginTest` (4 tests, dont `generatePlan name is free
  for the planner plugin`) → FAILED.
- **GREEN** : task codebase renommée `generateAugmentedPlan` (planner garde
  `generatePlan` — c'est son nom public/README/CLI). Baselines mises à jour
  (`CodebasePluginTest` 16 tests, `TaskSchemaScannerTest` 7).
- **Preuve** : les deux plugins s'appliquent désormais ; `generatePlan` est
  libre pour planner.
