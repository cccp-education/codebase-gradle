== Leçons

. `implementation(platform(...))` ne propage PAS les contraintes du BOM aux
  consommateurs transitifs — c'est un comportement Gradle documenté. La solution
  est de versionner explicitement toutes les deps dans le TOML.
. `api(platform(...))` ne change rien au `.module` non plus — le BOM reste
  invisible aux consommateurs transitifs.
. Le pattern `codex-plugin:0.0.2` (publié Central) confirme : versionner
  explicitement toutes les deps externes dans le TOML est la bonne approche.
