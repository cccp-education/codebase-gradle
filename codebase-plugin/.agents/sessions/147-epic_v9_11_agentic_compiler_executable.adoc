== Leçons

* Garder `CompiledArtifact` comme data class centrale mais lui adjoindre un `payload` évite de casser les consommateurs existants (enforcement, ingestion report).
* Le pattern `compileExecutable()` permet de séparer la description de l'artefact de sa logique d'exécution.
* Prochaine étape naturelle : câbler `ExecutableArtifact` dans `AgenticIngestor` pour stocker/exécuter les règles directement depuis le rapport d'ingestion (V-9.12).
