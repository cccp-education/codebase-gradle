== Leçon

Le pont N0↔N1 est fonctionnel : un `SessionPrompt` (data class pure) peut être
injecté dans une tâche Gradle, exécuté via `VibecodingGraph`, et produire un
`SessionResponse` structuré. La prochaine étape (SP-2) est le mode daemon/serveur
pour éviter la latence de compilation à chaque tour de dialogue.
