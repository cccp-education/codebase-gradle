== Leçons

. **Bug invariant koog state loop** : quand un graphe koog reboucle sur un
  nœud amont, les champs du tour précédent (`trainResult`, `proposal`,
  `validationScore`) doivent être explicitement resetés avant de re-entrer.
  Les invariants croisés `init` catch ce bug au runtime — TDD strict
  révèle l'erreur au premier test de loop. Pattern à documenter pour les
  futurs graphes itératifs (Cross-borough teaching : slider SLD-8.3 n'avait
  pas de loop, d'où l'absence de ce piège là-bas).
. **Backtick Kotlin illegal chars** : les noms de tests avec `..` sont
  rejetés par Kotlin ( Name contains illegal characters: .. ). Utiliser
  `0 to 1 range` à la place de `0..1`.
. **Pattern DDD port/fake/adapter** : `FineTuningGraph` consomme 3 ports
  (`FineTuningPromptBuilder`, `FineTuningLlm`, `FineTuningPipeline`) —
  tous synchrones, tous unit-testable avec fakes. L'adapter production
  (`OllamaFineTunerAdapter` US-2) vit hors du graphe. Pattern identique
  à `DeckPipelineGraph` + `DeckLlm` + `DeckPromptBuilder`.
