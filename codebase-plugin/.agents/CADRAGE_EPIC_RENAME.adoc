== Contexte

Les métiers vendus (fond de commerce, talaria.school) sont des termes
privés. Leur présence dans le nommage d'APIs publiques Apache 2.0 :
(1) banalise le terme du métier dans l'OSS, (2) condamne à des vagues
de renommage coûteuses quand le portefeuille grandit. La bonne heure est
maintenant — les usages sont encore peu profonds (~200 occurrences, 80%
tests/docs).

== Décisions de nommage (actées pilote)

|===
| Terme privé | Terme public | Sémantique
| métier documentaire | content | catégorie de contenu documentaire générique
| métier technique | coding | catégorie de contenu technique/code
|===

*Principe* : les plugins publics décrivent des capacités (assembler/
valider/ingérer du content, expertiser du coding) — chaque client
apporte son corpus. Le métier (et futurs) vit en privé
(`office/` + `training-gradle`), jamais dans le nommage public.

== Décisions techniques

- D1 : `FpaPageResolver` → `ContentPageResolver` — la convention split
  pages `NNN_N.adoc` devient une convention content générique (tout
  livre scanné page par page), un métier n'en est qu'un usage.
- D2 : `fpaAwareResolver()` → `contentAwareResolver()` (signature et
  câblage `AssembleBookTask` suivent).
- D3 : `Domain` codebase → valeurs `CODING` / `CONTENT`. Le couple
  métier (ex-FPA/CDA) disparaît du code public.
- D4 : défaut `-Pdomain` préservé : `orElse("CODING")` (comportement
  identique à l'ex-CDA défaut).
- D5 : keywords `DeterministicOffTopicDetector` — liste CODING inchangée
  (déjà générique) ; liste CONTENT : `"fpa"` et `"cda"` **sortent**.
  *RÉVISÉ Vague 4 (2026-09-10)* : `qualiopi`, `rncp`, `afnor`, `vae`,
  `bloom` etc. **sortent AUSSI** (D5/D11 abrogées — tout le champ lexical
  métier sort des repos publics ; logique transfusée dans
  `training-gradle/.agents/TRANSFER_LEXIQUE_FORMATION.adoc`).
- D6 : plantuml registry — les marques métier (ex-`"FPA"`/`"CDA"`) sortent du registre
  non-traductible (marques du pilote, pas acronymes génériques).
- D7 : backward compat NON préservée (renommage dur — boroughs jeunes,
  peu de consommateurs externes, moins de dette). Breaking change
  assumé et documenté (README + changelog bump).
- D8 : gouvernance (EPICs, cadrages) renommée avec mention "ex-métier" en
  historique seulement. AGENTS.adoc racine (privé) garde les métiers comme
  termes privés dans les sections privées ; les tables publiques boroughs
  passent aux termes neutres.
