== Leçons

* Isoler le diff incrémental dans des value objects purs (GovernanceFileSnapshot/GovernanceFileDiff/GovernanceFileChangeDetector) permet de tester la logique de détection sans Gradle ni infrastructure — TDD pur.
* La persistance JSON custom (regex parsing) a été un compromis pragmatique pour éviter une dépendance externe. La méthode load() défensive (null si fichier absent/vide/JSON invalide) garantit la robustesse.
* Le mode incrémental est rétrocompatible par défaut (incremental=false), ce qui préserve tous les tests existants sans modification.
* La contrainte Ollama doit être sauvegardée à deux niveaux (global AGENTS.adoc + borough AGENT.adoc) pour être chargée à chaque ouverture de session, pas seulement dans le borough concerné.
