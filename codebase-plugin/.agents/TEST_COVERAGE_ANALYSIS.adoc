== Leçons

* Séparer le registrar DDD de la tâche Gradle permet de tester l'enregistrement de tâches sans daemon.
* L'enrichissement du chunker doit être rétrocompatible : on ajoute la reconnaissance des verbes taxonomiques sans supprimer la logique `VALIDER` existante.
* Pour les tests Cucumber, capturer le `Project` Gradle dans le World permet de vérifier l'existence réelle des tâches dynamiques après ingestion.
* Les tâches dynamiques doivent utiliser des noms stables (id tronqué + type) pour éviter les collisions tout en restant déterministes.
