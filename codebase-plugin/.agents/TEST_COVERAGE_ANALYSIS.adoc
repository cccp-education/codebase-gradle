== Leçons

* Séparer modèle DDD (`GovernanceSummaryConfig`) de l'extension Gradle facilite les tests purs.
* `project.providers.gradleProperty()` ne lit pas `extraProperties` de `ProjectBuilder` ; utiliser un vrai `gradle.properties` pour tester le CLI override.
* Garder `strictValidation` en propriété task interne pendant la transition V-9.16→V-9.17 préserve la rétrocompatibilité, mais la prochaine étape doit unifier la source de vérité dans `GovernanceSummaryConfig`.
