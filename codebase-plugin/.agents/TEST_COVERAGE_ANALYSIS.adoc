== Leçons

* Désactiver `strictValidation` par défaut (`convention(false)`) préserve la rétrocompatibilité.
* `GradleException` est le type d'exception approprié pour faire échouer proprement une tâche Gradle.
* Partager les steps Cucumber entre EPICs proches (V-9.15/V-9.16) via des tags combinés réduit la duplication.
* Corriger une régression pré-existante découverte lors d'un run de validation globale est préférable à l'ignorer.
* Le catalogue de versions est auto-chargé par Gradle depuis `gradle/libs.versions.toml` à la racine ; pas besoin de `versionCatalogs` explicite.
