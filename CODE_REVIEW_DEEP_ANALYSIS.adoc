=== Detailed Build Configuration Review

==== 2.1 The Empty Root build.gradle.kts Problem

**Current State (lines 1):**
```kotlin
// Temporairement vide pour permettre le publishToMavenLocal du sous-projet
```

**Analysis:**

This is an **anti-pattern** for several reasons:

1. **Loss of centralized configuration** → No shared dependency management
2. **No repository definition** → Duplication in each subproject
3. **No version management** → Each plugin versions independently
4. **No build conventions** → No shared task configuration
5. **Unclear build intent** → Comment doesn't explain the real reason

**Impact:** ⚠️ Medium
- Creates maintenance burden (repeat config in `codebase-plugin/build.gradle.kts`)
- Makes multi-module builds harder to extend
- Complicates future CI/CD setup

**Root Cause Analysis:**

The comment suggests this was a temporary workaround for `publishToMavenLocal`. However:
- Gradle multi-project builds support `publishToMavenLocal` in subprojects without an empty root
- The root should define shared configuration even if individual subprojects override

**Recommendation:** Implement a proper root build.gradle.kts

```kotlin
// build.gradle.kts (ROOT)
plugins {
    id("org.jetbrains.kotlin.jvm") version "2.3.20" apply false
    id("com.gradle.plugin-publish") version "2.1.0" apply false
}

allprojects {
    group = "education.cccp"
    version = "0.0.2"
    
    repositories {
        mavenLocal()
        mavenCentral()
        gradlePluginPortal()
    }
}

subprojects {
    // Apply shared conventions
    apply(plugin = "kotlin")
    
    kotlin {
        jvmToolchain(24)
    }
}
```

**Benefits:**
- ✅ Single source of truth for versions
- ✅ Easier to scale to 2+ subprojects
- ✅ `publishToMavenLocal` works out-of-box
- ✅ Clearer build intent

**Effort:** ~15 minutes

```kotlin
// Cucumber Task Factory
// ============================================================================

data class CucumberTaskSpec(
    val taskName: String,
    val description: String,
    val filterClass: String,
    val timeout: Duration = Duration.ofMinutes(15),
)

fun Project.registerCucumberTask(spec: CucumberTaskSpec) = tasks.register<Test>(spec.taskName) {
    description = spec.description
    group = "verification"
    
    testClassesDirs = sourceSets.test.get().output.classesDirs
    classpath = configurations.testRuntimeClasspath.get() +
        sourceSets.test.get().output +
        sourceSets.main.get().output +
        files(tasks.jar.get().archiveFile)
    
    dependsOn(tasks.classes)
    useJUnitPlatform { excludeEngines("junit-jupiter") }
    systemProperty("cucumber.junit-platform.naming-strategy", "long")
    maxHeapSize = "1g"
    maxParallelForks = 1
    forkEvery = 1
    jvmArgs(
        "-XX:+UseSerialGC",
        "-XX:MaxMetaspaceSize=256m",
        "-XX:TieredStopAtLevel=1"
    )
    timeout.set(spec.timeout)
    
    testLogging {
        events("passed", "skipped", "failed")
        showStandardStreams = true
        exceptionFormat = FULL
    }
    
    outputs.upToDateWhen { false }
    filter { includeTestsMatching(spec.filterClass) }
}

// ============================================================================
// Define all Cucumber tasks in one place
// ============================================================================

val cucumberSpecs = listOf(
    CucumberTaskSpec(
        taskName = "cucumberTest",
        description = "Runs Cucumber BDD tests (EPIC 9 — pgvector infra)",
        filterClass = "codebase.scenarios.CucumberRunner",  // Main runner
    ),
    CucumberTaskSpec(
        taskName = "cucumberTestEpicV6",
        description = "Runs Cucumber BDD tests — EPIC V-6 (Feedback Loop)",
        filterClass = "codebase.scenarios.EpicV6CucumberRunner",
        timeout = Duration.ofMinutes(8),  // Shorter timeout
    ),
    CucumberTaskSpec(
        taskName = "cucumberTestEpicV7",
        description = "Runs Cucumber BDD tests — EPIC V-7 (Resume Session)",
        filterClass = "codebase.scenarios.EpicV7CucumberRunner",
        timeout = Duration.ofMinutes(8),
    ),
    // ... 22 more specs, each one line (after extrapolation)
)

// Register all tasks
cucumberSpecs.forEach { registerCucumberTask(it) }
```

**Benefits:**
- ✅ Reduces 728 lines → ~80 lines (89% reduction)
- ✅ Single source of truth for task defaults
- ✅ Easy to add new Epic tasks (1 line instead of 30)
- ✅ Timeout changes: 1 line instead of 24

- ✅ More testable (factory function is unit-testable)

==== 2.3 Global Test Configuration Consolidation

**Current State (lines 815-819):**

```kotlin
tasks.withType<Test>().configureEach {
    ignoreFailures = true
    useJUnitPlatform()
    jvmArgs("-XX:+EnableDynamicAgentLoading")
}
```

**Analysis:**

This is good (centralized test config), but:
- `ignoreFailures = true` is dangerous (hides failures in CI)
- No explanation for `EnableDynamicAgentLoading`
- Inconsistency: specific tasks define `useJUnitPlatform` again

**Recommendation:**

```kotlin
tasks.withType<Test>().configureEach {
    // Only ignore failures for non-critical tasks
    ignoreFailures = !isCI()
    
    useJUnitPlatform()
    
    // Enable dynamic agent loading for LLM tools (koog-agents, langchain4j)
    jvmArgs("-XX:+EnableDynamicAgentLoading")
    
    // Performance: use G1GC for large heap allocations
    jvmArgs("-XX:+UseG1GC", "-XX:MaxGCPauseMillis=200")
    
    // Memory: aggressive garbage collection for test environments
    if (!isCI()) {
        jvmArgs("-XX:+UseStringDeduplication")
    }
}

// Helper function
fun isCI() = System.getenv("CI") != null || System.getenv("GITHUB_ACTIONS") != null
```

**Benefits:**
- ✅ Safer in CI (prevents silent failures)
- ✅ Better JVM tuning for test performance
- ✅ Documented reason for `EnableDynamicAgentLoading`

**Effort:** ~10 minutes

=== 3.2 Memory & Heap Allocation Issues

**Current Configuration (lines 99-101):**

```kotlin
maxHeapSize = "1g"      // 1 GB per Cucumber task
maxParallelForks = 1    // Only 1 JVM at a time
forkEvery = 1           // Spawn new JVM for each test
```

**Analysis:**

| Issue | Impact | Severity |
|-------|--------|----------|
| 1 GB heap for local dev too large | 🔴 OOM risk on 8GB machines | High |
| 24 tasks × 1 GB if run parallel | 🔴 24 GB needed! | Critical |
| forkEvery=1 creates overhead | 🟡 3-5s startup per task | Medium |
| No incremental caching | 🟡 Rebuilds each time | Medium |

**Recommendation: Adaptive Heap Configuration**

```kotlin
val heapSize = when {
    System.getenv("CI") != null -> "2g"    // CI: larger heap
    Runtime.getRuntime().maxMemory() < 8_000_000_000L -> "512m"  // <8GB RAM: small
    else -> "1g"                           // Dev: 1GB
}

val heapForCucumber = when {
    System.getenv("CI") != null -> "2g"
    else -> "512m"  // Local: smaller for Cucumber
}

tasks.withType<Test>().configureEach {
    maxHeapSize = heapForCucumber
    maxParallelForks = (Runtime.getRuntime().availableProcessors() / 2).coerceAtLeast(1)
    forkEvery = 100  // Reuse JVM for multiple tests (safer)
}
```

**Benefits:**
- ✅ Reduces local memory footprint: 1GB → 512MB (50% savings)
- ✅ Enables parallel task execution when RAM available
- ✅ Reduces JVM spawn overhead: forkEvery=1 → forkEvery=100
- ✅ Safe escalation in CI (2GB)

**Effort:** ~15 minutes

=== 3.4 JVM Tuning for Test Performance

**Current Configuration (lines 102):**

```kotlin
jvmArgs("-XX:+UseSerialGC", "-XX:MaxMetaspaceSize=256m", "-XX:TieredStopAtLevel=1")
```

**Analysis:**

| JVM Flag | Purpose | Assessment |
|----------|---------|-----------|
| `-XX:+UseSerialGC` | Single-threaded GC | ⚠️ Old choice (G1GC better for modern JVMs) |
| `-XX:MaxMetaspaceSize=256m` | Class metadata buffer | ✅ Reasonable for Kotlin/tests |
| `-XX:TieredStopAtLevel=1` | Disable JIT compilation | ⚠️ Good for fast startup, bad for long runs |

**Recommendation: Better GC Configuration**

```kotlin
val jvmGcArgs = when {
    System.getenv("CI") != null -> {
        // CI: optimize for throughput
        listOf(
            "-XX:+UseG1GC",
            "-XX:MaxGCPauseMillis=200",
            "-XX:+ParallelRefProcEnabled"
        )
    }
    else -> {
        // Local: optimize for startup
        listOf(
            "-XX:+UseSerialGC",  // Keep serial GC for predictability
            "-XX:TieredStopAtLevel=4"  // Allow some JIT optimization
        )
    }
}

val metaspaceArgs = listOf(
    "-XX:MaxMetaspaceSize=512m",  // More headroom for Kotlin
    "-XX:CompressedClassSpaceSize=256m"
)

tasks.withType<Test>().configureEach {
    jvmArgs(jvmGcArgs + metaspaceArgs)
}
```

**Benefits:**
- ✅ G1GC better for CI (more predictable pause times)
- ✅ More metaspace for Kotlin classes
- ✅ Allows some JIT compilation on local (faster long-running tests)

**Effort:** ~20 minutes

```kotlin
    }
```

=== A.1 Complete Refactored Cucumber Task Factory

[source,kotlin]
----
// ============================================================================
// Cucumber BDD Task Factory (DRY Pattern)
// ============================================================================

import java.time.Duration

/**
 * Specification for a Cucumber test task.
 * 
 * @param taskName Gradle task name (e.g., "cucumberTestEpicV6")
 * @param description Human-readable description
 * @param filterClass Fully qualified name of Cucumber runner class
 * @param timeout Maximum execution time (default: 15 minutes)
 */
data class CucumberTaskSpec(
    val taskName: String,
    val description: String,
    val filterClass: String,
    val timeout: Duration = Duration.ofMinutes(15),
)

/**
 * Factory function to create a Cucumber test task with standard configuration.
 * 
 * Usage:
 *   registerCucumberTask(CucumberTaskSpec(
 *       taskName = "cucumberTestMyEpic",
 *       description = "Test my epic",
 *       filterClass = "codebase.scenarios.MyEpicRunner",
 *       timeout = Duration.ofMinutes(8)
 *   ))
 */
fun Project.registerCucumberTask(spec: CucumberTaskSpec) = tasks.register<Test>(spec.taskName) {
    description = spec.description
    group = "verification"
    
    // Classpath configuration
    testClassesDirs = sourceSets.test.get().output.classesDirs
    classpath = configurations.testRuntimeClasspath.get() +
        sourceSets.test.get().output +
        sourceSets.main.get().output +
        files(tasks.jar.get().archiveFile)
    
    // Test execution
    dependsOn(tasks.classes)
    useJUnitPlatform { 
        excludeEngines("junit-jupiter")  // Only run Cucumber
    }
    
    // Cucumber configuration
    systemProperty("cucumber.junit-platform.naming-strategy", "long")
    
    // Memory and GC
    maxHeapSize = determineHeapSize()
    maxParallelForks = determineForks()
    forkEvery = 100  // Reuse JVM for multiple tests
    
    jvmArgs(
        "-XX:+UseSerialGC",
        "-XX:MaxMetaspaceSize=512m",
        "-XX:CompressedClassSpaceSize=256m",
        "-XX:+EnableDynamicAgentLoading",
        "-XX:TieredStopAtLevel=4"
    )
    
    // Timeout
    timeout.set(spec.timeout)
    
    // Logging
    testLogging {
        events("passed", "skipped", "failed")
        showStandardStreams = true
        exceptionFormat = FULL
    }
    
    // Don't use cache (tests are non-deterministic)
    outputs.upToDateWhen { false }
    
    // Filter to specific test class
    filter { includeTestsMatching(spec.filterClass) }
}

/**
 * Determine heap size based on environment and available RAM.
 */
private fun determineHeapSize(): String = when {
    System.getenv("CI") != null -> "2g"           // CI: larger heap
    Runtime.getRuntime().maxMemory() < 8_000_000_000L -> "512m"  // <8GB: small
    else -> "1g"                                  // Dev: 1GB
}

/**
 * Determine number of parallel forks based on CPU count.
 */
private fun determineForks(): Int = 
    (Runtime.getRuntime().availableProcessors() / 2).coerceAtLeast(1)

// ============================================================================
// Define all Cucumber test tasks
// ============================================================================

val cucumberTaskSpecs = listOf(
    CucumberTaskSpec(
        taskName = "cucumberTest",
        description = "Runs all Cucumber BDD tests (EPIC 9 — pgvector infra)",
        filterClass = "codebase.scenarios.CucumberRunner",
        timeout = Duration.ofMinutes(15)
    ),
    CucumberTaskSpec(
        taskName = "cucumberTestEpicV6",
        description = "Runs Cucumber BDD tests — EPIC V-6 (Feedback Loop — error→replan→retry)",
        filterClass = "codebase.scenarios.EpicV6CucumberRunner",
        timeout = Duration.ofMinutes(8)
    ),
    CucumberTaskSpec(
        taskName = "cucumberTestEpicV7",
        description = "Runs Cucumber BDD tests — EPIC V-7 (Resume Session)",
        filterClass = "codebase.scenarios.EpicV7CucumberRunner",
        timeout = Duration.ofMinutes(8)
    ),
    // ... (20+ more tasks, each one line)
)

// Register all tasks
cucumberTaskSpecs.forEach { registerCucumberTask(it) }
